# Трассировка требований бланка → реализация

Дата: 2026-11-21
Назначение: доказать, что каждый пункт задания закрыт; основа для пояснительной записки и защиты.

## 1. Общие требования (п. 3.2)

| Пункт бланка | Реализация | Где проверять |
|---|---|---|
| Клиент-серверное приложение с самостоятельно установленным веб-сервером | Express 5 на Node.js, `npm start`, Dockerfile | `src/server.js`, `Dockerfile`, `docs/deployment.md` |
| Архитектура MVC или MVP | MVC: routes → controllers → services → repositories → views | `src/` структура, §5 спеки |
| CommonJS / UMD / ES-модули | ESM во всём проекте | `package.json: "type": "module"` |
| HTML/XML, DHTML, JavaScript | HTML5 (EJS), React-острова, vanilla JS хелперы | `src/views`, `client/` |
| Общая тема и дизайн, гиперссылки между страницами | единый layout, сайдбар, хлебные крошки, ссылки | `src/views/layouts/app.ejs` |
| Одна каскадная таблица стилей | единственный `public/css/app.css` | grep по `<link rel="stylesheet"` — один результат |
| Логин/пароль в БД | таблица `users`, argon2id-хеши | `db/migrations/001_init.sql` |
| Ресурсные данные (изображения) в БД | `media_assets` (BYTEA), отдача `/media/:id` с ETag | `src/repositories/media.repo.js` |
| Ссылочная целостность | PostgreSQL FK, CHECK, UNIQUE, транзакции | миграции, `\d+` в psql |
| Node.js + npm + Express | Node 24 LTS, Express 5 | `package.json` |
| Бизнес-логика на JavaScript | сервисы на чистом JS с JSDoc | `src/services/` |
| Клиент на HTML5/CSS3/DHTML/JS-библиотеках | React 19, Recharts, ES-модули | `client/` |
| СУБД на выбор с ссылочной целостностью | PostgreSQL 18 | `docker-compose.yml`, `.env.example` |

| Требование | Реализация |

## 4. Безопасность (п. 3.3.4)

| Требование | Реализация |
|---|---|
| Защита хранимых данных | argon2id для паролей; секреты вне репозитория; опционально pgcrypto не нужен — PII минимальны |
| Шифрование передаваемых данных | TLS на reverse-proxy, secure-cookies, HSTS в production |
| Резервное копирование | `scripts/backup.js`: pg_dump -Fc + AES-256-GCM, retention, `scripts/restore.js`, проверка восстановления |
